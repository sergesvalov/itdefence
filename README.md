# 🏢 Office TD — Enikey Defense

**Tower Defense** в офисном сеттинге, игра по книге. Что бы ни делали её герои — автоматизировали, писали Программу, собирали хранилище из хлама — на самом деле они защищаются от потока задач и проблем. Поэтому это tower defense: Петя сидит в своём кабинете, к нему идут коллеги с тасками, а всё, что он строит, — это оборона.

## 🎮 Стек

| Технология | Версия |
|---|---|
| Phaser 3 | ^3.88 |
| TypeScript | ~5.8 |
| Vite | ^6 |
| Node.js (CI) | 22 LTS |

## 🚀 Локальный запуск

```bash
npm install
npm run dev        # http://localhost:5173
```

## 🔧 Сборка

```bash
npm run build          # web-версия → dist/
npm run build:electron # Electron-версия → dist/ (base='./')
npm run build:cap      # Capacitor-версия → dist/ (base='./')
```

## 🧪 Тестирование

```bash
npm run test           # Запуск Unit-тестов (Vitest)
npm run test:e2e       # Запуск E2E-тестов (Playwright)
```

В проекте настроено сквозное (E2E) тестирование критических путей (например, прохождение туториала) с помощью Playwright, а также юнит-тестирование с помощью Vitest. Эти тесты интегрированы в Jenkins-пайплайн и выполняются перед сборкой.

## 📦 Платформенные пакеты

```bash
# Windows: .exe инсталлятор (нужен Node + electron-builder)
npm run dist:win       # → release/*.exe

# Android: инициализация (первый раз)
npx cap add android
npm run cap:sync       # vite build + cap sync → android/
npm run cap:open       # открыть в Android Studio
```

Экран портретный (ширина 480, высота подстраивается под соотношение сторон
устройства — от 720 до 1200, см. `initLayout()` в `src/config.ts`) — коллеги
заходят через дверь ресепшена в верхней части и идут вниз через кабинет Пети
к его столу. Кабинет — это и есть игровое поле для построек.

## 🧭 Меню, обучение и магазин

Игра стартует с главного меню (`MainMenuScene`): **Кампания**, **Обучение**,
**Свободная игра** (бесконечные волны), **Магазин**.

- **Обучение** — пошаговый туториал с Петей (`TutorialManager`): игра ставится
  на паузу на каждом шаге, пока игрок не переставит шкаф и не построит кулер.
  Остальные постройки на это время заблокированы.
- **Магазин** (`UpgradeScene`) — постоянные улучшения за «премию», которая
  начисляется после каждого Game Over (`номер волны × 10`). Прогресс хранится
  в `localStorage` (`MetaProgression`). Каждое улучшение — до 5 уровней по 150 💰:

| Улучшение | Эффект за уровень |
|---|---|
| Расширение Инбокса | +2 к лимиту очереди |
| Финансовая Подушка | +50 стартовых денег |
| Крепкие Нервы | +10% урона башен |
| Долгий Митинг | +2с к длительности щита |

## 📖 Кампания

Кампания идёт по книге: каждый акт — одна из попыток Пети прожить эту жизнь
иначе, каждая глава акта — эпизод из неё. Перед главой и после неё
показывается короткий текст из книги (`StoryScene`), главы внутри акта
открываются по порядку, сами акты доступны все сразу (`CampaignScene`). В
каждой главе нужно продержаться заданное число спринтов.

Коллеги в кампании несут не безликие тикеты, а конкретные проблемы главы —
подпись над каждым («Принтер жуёт бумагу», «Смета», «Горит релиз»). Набор
построек — то, чем герои в этот момент от них защищаются. Цвет подписи
подсказывает особое правило главы.

### Акт I. Системный администратор

| # | Глава | Что нового |
|---|---|---|
| 1 | Один день эникейщика | Только кофе, кулер и мебель |
| 2 | Золотой образ | Документация и роутер |
| 3 | Помощник на вырост | Стол напарника (Вася), бронированные бухгалтеры |
| 4 | Пётр и Петр | **Дубли** (фиолетовая подпись): карточка через «ё» распадается на два дубля, если убрать её чем угодно, кроме документации |
| 5 | Программа | Кондиционер, в финале — Марья Ивановна с бумажным адом |
| 6 | Хранилище с характером | **Спящие диски:** простаивающая постройка засыпает; тап будит её сразу, с Васей она просыпается быстрее |
| 7 | Тот самый день | Диски спят, а на третьем спринте «умирает» самая дорогая постройка |
| 8 | Строка расходов | Финдиректор каждый спринт сокращает самую дорогую постройку |

### Акт II. Инженер

| # | Глава | Что нового |
|---|---|---|
| 1 | Ваучеры на экзамены | Снова с нуля; в финале — экзамен вендора |

### Акт III. Автоматизатор

| # | Глава | Что нового |
|---|---|---|
| 1 | Смотри на доску | **Две двери:** два продукта, задачи идут из обеих |
| 2 | Полная свобода | Премии за спринт нет — «денег пока нет» |
| 3 | База феникс | **Зависшие контейнеры:** постройки время от времени виснут; тап переподнимает, но прокачка пропадает |

| 7 | Озеро | Почти все задачи «не стоят того»: дойдут — ничего не случится, награды за них нет. Важны только редкие настоящие (красная подпись) |

модификаторы лежат в `src/campaign/act1.ts` … `act3.ts`, все доступные
модификаторы — в `LevelDef` (`src/campaign/types.ts`). Чтобы добавить главу
или акт, достаточно дописать объект в список.

## 💰 Экономика

Петя стартует с деньгами (`STARTING_MONEY`, 150). Дальше деньги приходят из
двух источников: **награда за каждого коллегу, которого остановили башни**
(`bounty` в `COWORKER_VARIANTS` — от 3 за стажёра до 60 за босса), и
небольшой бонус за зачищенную волну (`WAVE_MONEY_AMOUNT`, 30). Коллеги,
дошедшие до стола, убранные ультимейтом или перехваченные напарником,
награды не дают.

За деньги можно ставить башни и улучшать их. Тап по башне открывает меню:
**⬆ улучшить** (до 3 уровней: +60% базового урона, +20 к радиусу и на 15%
быстрее стрельба за уровень; цена — `стоимость × текущий уровень`) и
**продать** (возврат `TOWER_SELL_REFUND`, 60% от всего вложенного).

Волна 1 начинается сразу. Дальше — цикл: волна идёт, пока не будут
обработаны (убиты или дошли до стола) все её коллеги, затем начисляются
деньги и наступает **пауза** — можно спокойно тратить накопленное на
постройку и апгрейды, без давления таймера. Следующая волна не начнётся,
пока не тапнешь по кнопке ▶️ **«Начать волну»** (под кнопками способностей,
в правом верхнем углу — появляется только на время паузы).

## 👥 Коллеги (враги)

В волне `ENEMIES_PER_WAVE_BASE + волна × ENEMIES_PER_WAVE_GROWTH` коллег, с
каждой волной они выходят чаще и становятся живучее: HP растёт на 15% от
базы за волну плюс квадратичная добавка (`WAVE_HP_GROWTH`, `WAVE_HP_GROWTH_SQ`). Типы заданы в `COWORKER_VARIANTS`
(`src/config.ts`), новые появляются по мере роста волн (`WaveManager`):

| Коллега | С волны | HP | Скорость | Награда | Особенность |
|---|---|---|---|---|---|
| Коллега | 1 | ×1 | ×1 | 5 | — |
| 🐣 Стажер | 2 | ×0.4 | ×1.2 | 3 | Слабый, но быстрый |
| ⚡ Agile Коуч | 3 | ×0.7 | ×1.5 | 6 | Самый быстрый |
| 🛡️ Бухгалтер | 4 | ×2.5 | ×0.65 | 12 | **Броня:** получает половину урона от всего, кроме Docs |
| 💻 Удаленщик | 6 | ×0.8 | ×1.2 | 7 | Игнорирует мебель — идёт к столу по прямой |
| 👿 Заказчик | каждая 5-я | ×15 | ×0.35 | 60 | Босс, выходит первым в волне; ультимейтом не убирается |
| 📎 Марья Ивановна | глава «Программа» | ×13 | ×0.4 | 60 | Босс кампании: лёгкая броня (−30% урона от всего, кроме Docs) |

## 📥 Очередь задач (Inbox)

Коллега, дошедший до стола, больше не отнимает у Пети «жизнь» напрямую —
он кидает свою задачу в **Inbox** (`src/systems/Inbox.ts`), очередь с
лимитом (`INBOX_LIMIT`, по умолчанию 10, растёт с улучшением из магазина).
Превысил лимит — Game Over.

Петя **саморешает** задачи: каждые `INBOX_RESOLVE_INTERVAL_MS` (5с) он
автоматически снимает задачу с начала очереди — это происходит само,
без участия игрока. Коллеги подходят к столу быстрее, чем Петя успевает
разгребать, так что очередь копится — единственный способ сдержать наплыв
это выбивать коллег башнями по пути (🚰 Cooler, 📖 Docs и остальные), пока
они ещё идут по коридору, не дав им вообще добраться до стола.

Часть коллег (`URGENT_TASK_CHANCE`, 15%) несёт **срочную задачу** 🔴 —
такая, попав в Inbox, встаёт не в конец очереди, а **в начало** (обгоняет
всех) — её тикет на враге тоже подсвечен красным, чтобы такого коллегу
было видно заранее и приоритетно снять его башнями. В HUD под счётчиком
Inbox — мини-ряд из `INBOX_LIMIT` значков, показывающий очередь как есть
слева направо (левый — следующий на решение): 🔴 срочная, 🟡 обычная,
▫️ свободный слот.

## 🎫 Способности

Две заряжаемые способности, кнопки — в правом верхнем углу (кольцо вокруг
кнопки показывает прогресс зарядки; когда полная — кнопка пульсирует).

**🎫 «Создай тикет»** — глобальный удар, откат 30с (`ULTIMATE_COOLDOWN_MS`).
По тапу половина живых коллег на экране (округление вверх,
`ULTIMATE_KILL_FRACTION`) мгновенно «сдувается» и уходит — им лень заводить
официальную заявку в Jira. Считается как обычное устранение для прогресса
волны — так же приближает её зачистку и следующую паузу. Босса тикетом не
выгнать: он только теряет 20% максимального HP
(`ULTIMATE_BOSS_DAMAGE_FRACTION`).

**🛡️ «Я на митинге»** — временная неуязвимость двери, откат 25с
(`SHIELD_COOLDOWN_MS`), длительность 6с (`SHIELD_DURATION_MS`). Пока щит
активен, любой дошедший до стола коллега вместо удара по Пете застревает
у таблички «Не беспокоить» и получает периодический урон от ожидания
(`SHIELD_DOT_DAMAGE` каждые `SHIELD_DOT_INTERVAL_MS`) — башни тоже продолжают
по нему бить. Если не добить за время действия щита — по истечении коллега
всё же врывается и засчитывается как обычно.

## 🪑 Мебель

Кроме башен, в кабинет можно ставить мебель — она бесплатная, но у каждого
типа конечный запас (`FURNITURE_TYPES_DATA`, `src/config.ts`). Мебель не
атакует, это чистое препятствие на пути коллег — они прокладывают маршрут в
обход (`Pathfinder`), и он пересчитывается при каждой перестановке. В начале
раунда в кабинете уже стоят 3 случайных предмета (они идут в счёт запаса):

| Мебель | Запас | Особенность |
|---|---|---|
| 🗄️ Шкаф | 5 | Непроходим — коллеги огибают его |
| 🗃️ Тумбочка | 6 | Непроходима, но компактнее шкафа |
| 🛋️ Диван | 3 | Непроходим; коллега, дошедший до него, останавливается и садится на `SOFA_SIT_DURATION_MS` (3с) — башни всё это время продолжают по нему бить — прежде чем встать и пойти дальше |

Мебель делит общий цикл выбора построек с башнями (клавиши 1-9, правый
клик, тап по строке типа в HUD — сначала идут 6 башен, потом 3 предмета
мебели). Уже поставленную мебель можно **передвинуть**: тап по ней
поднимает её (следует за курсором), следующий тап по свободному месту в
кабинете кладёт её туда; тап по невалидному месту возвращает мебель туда,
где она стояла.

## 🕹️ Управление

| Действие | Управление |
|---|---|
| Поставить башню/мебель | Клик/тап по кабинету |
| Улучшить / продать башню | Клик/тап по башне → кнопка в появившемся меню |
| Ускорить игру | Кнопка **×1 / ×2** слева над кабинетом |
| Переставить мебель | Клик/тап по ней (взять), клик/тап по новому месту (положить) |
| Сменить тип постройки | Клавиши 1-9, правый клик, или тап по строке типа в HUD |
| Посмотреть радиус башни | Навести курсор / тап по башне |
| Активировать «Создай тикет» | Тап по кнопке 🎫 (когда заряжена) |
| Активировать «Я на митинге» | Тап по кнопке 🛡️ (когда заряжена) |
| Начать следующую волну | Тап по кнопке ▶️ (появляется в паузе между волнами) |
| Переставить стол напарника | Тап по нему в паузе между волнами → ✋ |
| Вернуться в меню (после Game Over) | **R** или тап по экрану |

### Типы башен

Характеристики и стоимость заданы в `TOWER_VARIANTS_DATA` (`src/config.ts`).

| Башня | Урон | Скорострельность | Радиус | Стоимость | Особенность |
|---|---|---|---|---|---|
| 🚰 **Cooler** («Кулер») | 3 | - | 110 | 45 | **Приманка и Цепная реакция.** Враги отклоняются от маршрута, чтобы подойти к кулеру. При касании наносит урон; если коллега от него «сдулся», половина урона отскакивает в ближайших. |
| 📡 **Router** («Плохой коннект») | 0 | 1500мс | 100 | 50 | **AoE Замедление.** Испускает Wi-Fi импульс вокруг себя, временно замедляя («зависают») всех врагов в радиусе действия. |
| 📖 **Docs** («Бюрократия») | 6 | 2600мс | 160 | 100 | **Оглушение и Пробитие.** Медленная тяжёлая артиллерия. Бьёт самого «толстого» в радиусе, оглушает и игнорирует броню — ответ на Бухгалтера и босса. |
| ☕ **Coffee** («Кофе-брейк») | 1 | 700мс | 110 | 55 | **Скорострельность и замедление.** Дешёвая рабочая лошадка: частые выстрелы, каждый замедляет цель. |
| 🌬️ **AC** («Кондиционер») | 2 | 1600мс | 140 | 85 | **Урон по области (Сплэш).** Снаряд взрывается при попадании, нанося урон всем врагам в радиусе 60 — лучший выбор против толпы. |
| 🧑‍💻 **Напарник** | 0 | - | - | 150 | **Перехват задач.** Стол напарника забирает на себя каждого второго коллегу и решает его задачу сам — до 5 задач за волну (`PARTNER_TASKS_PER_WAVE`), к следующей волне он отдыхает. Доступен с 4-й волны (второй — с 7-й). |

Улучшение и продажа — через меню башни (см. «Экономика»).

## 🖼️ Графика

Вся графика векторная и нарисована кодом — растровых картинок в проекте нет.

- **Объекты** (башни, мебель, коллеги, стол Пети, дверь, портреты героев) — SVG-файлы в
  `public/assets/sprites/`. Их рисует скрипт
  [`tools/generate-art.mjs`](tools/generate-art.mjs): общая палитра, единый
  тёмный контур и один ракурс заданы там в одном месте, поэтому все объекты
  выглядят как один набор.
- **Стены и пол** рисуются прямо в игре (`src/rendering/MapRenderer.ts`).

Чтобы что-то перерисовать, поправьте соответствующую функцию в генераторе и
запустите:

```bash
node tools/generate-art.mjs
```

SVG-файлы руками не редактируются — следующий запуск их перезапишет. Список
спрайтов и размер, в котором Phaser растеризует каждый при загрузке, лежит в
`TEXTURE_ASSETS` (`src/config.ts`). Если файл не загрузился, объект рисуется
программной заглушкой, так что игра остаётся рабочей. Правила стиля —
[`public/assets/ART_BRIEF.md`](public/assets/ART_BRIEF.md).

## 🔄 CI/CD (Jenkins)

[`Jenkinsfile`](./Jenkinsfile) только подключает общую библиотеку и вызывает
её `declarativePipeline`; параметры проекта (стек, каталог и порт деплоя,
включённые стадии, кастомные стадии) лежат в
[`pipeline-config.yaml`](./pipeline-config.yaml).

### Этапы

```
Source Checkout       (+ чистка dist/release/android от прошлой сборки)
    ↓
Build Node Image      (пересобирается и пушится, только если изменился Dockerfile.build)
    ↓
Build Android Image   (аналогично — только при изменении Dockerfile.android)
    ↓
Install Dependencies  (npm ci, с постоянным кэшем — том itdefence-npm-cache)
    ↓
TypeScript Check      (tsc --noEmit)
    ↓
Test                  (Unit-тесты Vitest + E2E Playwright внутри Docker)
    ↓
┌───────────────────────────────────────┐  ← последовательно (ARM-хост не тянет parallel)
│ Build: Web           │ Build: Android          │
│ vite build:web       │ Capacitor + Gradle      │
│ → dist/ → Nginx-образ │ → android/...apk        │
│                       │ (кэш: itdefence-gradle-cache) │
└───────────────────────────────────────┘
    ↓
Archive (dist/**, **/*.apk)
    ↓
Deploy Web [только main] → docker compose (ssh) → /opt/itdefence на 192.168.0.222:7979
```

> **Windows .exe не собирается в этом пайплайне.** `electron-builder --win` создаёт
> NSIS-инсталлятор, а это требует Wine для запуска Windows-бинарников — на ARM64
> Linux-хосте Wine работал бы только через x86-эмуляцию (box64/qemu), что
> ненадёжно и очень медленно. Собирайте Windows-версию (`npm run dist:win`)
> либо локально на Windows, либо на отдельном Windows-агенте/раннере.

> **Android-сборка использует сторонний `aapt2` для arm64.** Google публикует
> `aapt2` только под x86_64/macOS/Windows, а Android Gradle Plugin тянет
> именно эту версию с Maven независимо от SDK build-tools — на ARM-хосте
> она не запускается. `Dockerfile.android` подкладывает вместо неё бинарник
> из [Commit451/android-arm-build-tools](https://github.com/Commit451/android-arm-build-tools)
> (MIT, пересобран из тегов релиза AOSP), запиненный на конкретный релиз и
> проверенный по SHA-256 при сборке образа. Если после апдейта AGP снова
> сломается (несовместимый флаг aapt2) — нужно поднять версию релиза в
> `Dockerfile.android` и обновить хэш.

> **JDK берётся не из apt, а из тарбола Eclipse Temurin.** Capacitor 7
> генерирует Android-проект под Java 21, а Debian bookworm пакует только
> openjdk-17 (openjdk-21 появился лишь в Debian 13). `Dockerfile.android`
> ставит [Temurin 21 arm64](https://github.com/adoptium/temurin21-binaries)
> из checksum-пиненного тарбола вместо apt-пакета.

### Jenkins Shared Library (`mylib`)

Часть логики пайплайна вынесена в общую библиотеку (Shared Library, исходный код: `git@github.com:sergesvalov/jenkins-shared-library.git`), которая подключается в начале `Jenkinsfile`:
```groovy
@Library('mylib@main') _
```
*(В настройках Jenkins эта библиотека должна быть добавлена под именем `mylib` с указанием данного репозитория).*

**Используемые функции из библиотеки:**
- `buildAndPushIfChanged`: Оптимизированная сборка Docker-образов. Собирает образ только если его ещё нет в реестре (проверка по хэшу `Dockerfile`), экономя время.
- `withNodeBuilder`: Обертка для запуска команд сборки в изолированном Docker-контейнере с Node.js, с пробросом кэша npm (`NPM_CACHE_VOLUME`) и правами root.
- `withAndroidBuilder`: Обертка для запуска сборки Android-проекта (Capacitor/Gradle) в изолированном контейнере, с пробросом кэша npm (`NPM_CACHE_VOLUME`), кэша Gradle (`GRADLE_CACHE_VOLUME`) и правами root.
- `signAndroidApk`: Выравнивает (zipalign) и подписывает (apksigner) собранный APK-файл с использованием параметров-ключей. Удобно переиспользуется для других Android-сборок.
- `deployDockerCompose`: Деплоит приложение через Docker Compose на удаленный сервер по SSH, создавая нужные директории и копируя конфигурацию.
